Complexity interpretation

For a graph with V virtual registers and E interference edges, adjacency-list graph storage is O(V + E). Building interference and heuristic coloring costs depend on implementation, graph density, CFG size, and spill retries; graph coloring in general is NP-complete. These measurements characterize this implementation, not an asymptotic bound.

Register group visualization

Organize the available physical registers into boxes. Each assignment is shown inside the group containing its physical register. This is a visualization of register partitions, not hardware memory segmentation or an independent bank-constrained allocation algorithm.
